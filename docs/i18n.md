# Internationalization

MOVRR uses the same lightweight, typed App Router architecture as
`movrr-waitlist`. English (`en`) is the default and has unprefixed URLs.
Dutch (`nl`) uses the `/nl` prefix.

## Source of truth

- `lib/i18n/config.ts` defines supported locales, the default locale, and the
  persistence/header names.
- `lib/i18n/routing.ts` owns every locale-aware path transformation.
- `proxy.ts` detects the path, persisted cookie, and `Accept-Language`, in that
  order. Public assets and API routes are excluded.
- `locales/en.ts` and `locales/nl/common.ts` contain matching, typed copy.
- `lib/i18n/dictionary.ts` loads English synchronously and Dutch dynamically.
- `lib/i18n/metadata.ts` creates localized canonical, hreflang, Open Graph, and
  Twitter metadata.

## Adding or changing copy

1. Add the typed field to the relevant interface in `locales/types.ts`.
2. Add the English value in `locales/en.ts`.
3. Add the native Dutch value in `locales/nl/common.ts`.
4. Pass only the relevant page or component namespace to the component. Shared
   chrome uses `CommonCopyProvider`; page client trees use `PageCopyProvider`.
5. Use `withLocalePath` for every internal link.

TypeScript is the missing-translation check: both dictionaries must satisfy the
same shape, and production builds do not ignore type errors.

Run `npm run verify:i18n` when adding routes or changing localized navigation.
It verifies route parity, dictionary namespaces, metadata, proxy behaviour,
locale-aware links, accessibility copy boundaries, forms, email, consent, and
sitemap integration. CI should run it together with `npm run lint`,
`npx tsc --noEmit`, and `npm run build`.

## Routing and SEO conventions

- Never add `/en`; English remains the canonical default.
- A Dutch counterpart must exist for every indexable English route.
- New pages must be added once to `PAGE_PATHS`; the sitemap then emits both
  locale URLs and their alternates automatically.
- Page routes use `buildPageMetadata` so canonical and `en`, `nl`, and
  `x-default` alternates stay aligned.
- The language switcher preserves the current path and query string, then
  persists the choice in the `movrr_lang` cookie.
